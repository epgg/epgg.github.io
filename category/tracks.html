Tracks

📄️What are tracks?

Tracks in the WashU Epigenome Browser are the rows of data shown under the ruler, one row per dataset. Each track reads data tied to genomic coordinates. When you move to a region, the Browser fetches the data for that region, reformats it and draws it.

📄️API based tracks

API based tracks get their data by sending requests to a web service (an API) instead of reading a track file. Two track types work this way: gene annotation tracks (geneAnnotation) and the SNV track (snp).

📄️Local tracks

Not every research group can set up a web server with CORS enabled. With local tracks you can view track files that are on your own computer. The files are read by your web browser only; they are not uploaded to any server. The files must be in the same formats as tracks hosted on a web server; see file-based tracks for the formats and how to prepare them.

📄️Local text tracks

Tracks are usually prepared in an indexed or binary format, such as bigWig, bigBed, HiC or bgzip-compressed and tabix-indexed files, so the browser can read just the region on screen. Sometimes it is more convenient to look at a plain-text file directly, without converting it first. Local Text Tracks reads a whole text file from your computer and shows it as a track. The file is not uploaded anywhere. Once it is loaded the track is fast, because no further network requests are needed.

📄️Dynamic tracks

Dynamic tracks show how data change across a series of steps (time points, developmental stages, cell types, ...) as an animation. Instead of stacking several tracks, a dynamic track draws one step at a time in the same track row and cycles through the steps in a loop.

📄️View 3D genome structure

The Browser can show 3D genome structure data next to your tracks. 3D structures are stored in the g3d format. Adding a g3d track opens a 3D viewer panel beside the genome browser instead of adding a track row. The viewer has a menu to change the resolution, the layout and the display style, to label genes and regions, and to paint the structure with numerical or annotation data.

📄️Image tracks

Image tracks place microscopy images on the genome. Each image is linked to the gene it is about (for example the gene knocked down or tagged in the experiment), so when you view a gene you can see the images of that gene from imaging studies. The Browser supports images from the Image Data Resource (IDR), with the track type omeroidr.
